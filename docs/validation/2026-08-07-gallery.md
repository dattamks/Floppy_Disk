# Gallery — feature summary + validation checklist (2026-08-07)

The **Gallery** is a first-class sidebar tab that gathers every photo, video and
audio track the owner has, across all folders, into one browsable surface. It's
a read-only lens over the file store (no new storage model) and is fully
scope-safe: a folder-scoped API key sees only the media under its subtree, and
nothing about storage configuration or credentials is ever exposed here.

OSS-now vs commercial-later: everything below ships in the standalone OSS
edition. Deferred, higher-value ideas that would sit naturally on top of this
tab (per-item version history, shared albums, face/scene grouping) stay on the
commercial roadmap and are not built here.

## What it does

- **Three categories** — Photos, Videos and Audio, each shown as its own titled
  section with a live count. A filter (All / Photos / Videos / Audio) narrows the
  view.
- **Date grouping** — within each category, media is grouped newest-first into
  `Today / Yesterday / This week / This month / "Month YYYY"` buckets, with a
  sticky sub-heading per group. A **Group by date** toggle turns it off/on.
- **Lightbox viewer** — click a photo to open it full-size and page through the
  whole category (prev/next buttons + ArrowLeft/ArrowRight; ends are disabled);
  a counter shows `n / total`. A video opens in an inline `<video>` player; an
  audio track opens in an inline `<audio>` player with a music-disc hero. Escape
  closes.
- **Per-item context menu** — right-click a tile (or the hover kebab) for
  **Info / Download / Move to trash**. The lightbox exposes the same actions.
- **Info panel** — name, type, size, dimensions, duration (video/audio),
  added-date, with a thumbnail and Download / Trash actions. Escape or backdrop
  closes it.
- **Undo on delete** — Move to trash is optimistic and shows a **Moved to trash**
  toast with an **Undo** that restores the file (via the existing trash/restore
  path). Failures surface an error and reload.

## Surfaces (Trinity)

- **UI** — `frontend/src/components/GalleryPage.jsx`, tab wired through
  `App.jsx` / `AppShell.jsx` / `Sidebar.jsx` / `view/AppView.jsx`.
- **API** — `GET /storage/media` (`MediaListView`): owner-scoped, key-scoped,
  images+videos+audio only, excludes trashed and pending, newest-first.
- **MCP / Graph** — unchanged: media are ordinary files, already surfaced by the
  existing file + graph tools; the Gallery adds no privileged data path.
